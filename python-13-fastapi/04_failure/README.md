# 04_failure — 失敗の表現

**この章の問い**: 4xx と 5xx の切り分けが、そのまま可用性 SLI の分母と分子になる。

| ファイル | 学ぶこと |
|---|---|
| `exception_handlers/` | 統一エラー形式、未捕捉例外の扱い、外に出さず内に残す |
| `status_code_policy/` | ステータスコードの判断表、429 と Retry-After |
| `sli_error_budget/` | SLI 定義文、SLO からエラーバジェットを計算する |

## 実行

```bash
python sli_error_budget/sli_error_budget.py
```

SLO ごとの許容ダウンタイムが表示されます。99.9% が月 43 分、
99.99% が月 4.3 分という桁感を、数字で持っておいてください。

## 合格基準

- [ ] 400/401/403/404/409/422/429 がそれぞれ何を意味するか即答できる
- [ ] 本来 4xx のものを 500 で返していると SLO が壊れる構造を説明できる
- [ ] 下流の 404 / タイムアウト / 500 を、自分は何で返すか方針を言える
- [ ] スタックトレースをレスポンスに漏らさず、ログには残す実装を書いた
- [ ] SLO 99.9% が月あたり何分に相当するか計算できる
- [ ] 担当システムの SLI 定義文（6項目）を実際に書いた

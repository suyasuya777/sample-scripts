**コマンドと結果をセットで書きます。** 結果の数字だけだと、1か月後に「どうやって出したか」が分からなくなります。

```
$ ss -Htan state time-wait | wc -l

```

**この記録には自分のアカウントの ARN や IP が入ります。公開リポジトリには置かないでください。**
